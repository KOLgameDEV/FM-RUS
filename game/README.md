# КАБИНЕТ · Футбольный менеджер

Браузерная игра-менеджер по российскому футболу: РПЛ, ФНЛ, ФНЛ-2, ФНЛ-3, Медийная лига, любители, FONBET Кубок и еврокубки — с живыми матчами, тактикой, трансферами и зарплатной ведомостью.

Работает полностью на статическом хостинге (GitHub Pages, Netlify, любой веб-сервер): без сборки, без npm, без бэкенда. Сохранения — в `localStorage` браузера (3 слота в «папке Кабинет»).

## Запуск

Откройте `index.html` в браузере. Локально можно так:

```bash
python3 -m http.server 8080
# затем http://localhost:8080
```

## Структура

```
.gitignore        — служебные исключения
.github/workflows/pages.yml — публикация на GitHub Pages
index.html        — оболочка и порядок загрузки скриптов
css/style.css     — дизайн-система (тёмная тема, золото, CSS-поле)
js/data.js        — игровые данные: 182 клуба, 16 лиг, формации, пулы имён, рынки
js/engine.js      — движок: генерация игроков, xG-модель матча, сезон, трансферы
js/game.js        — состояние, слоты сохранений, маршрутизация, действия (ACT)
js/match.js       — живой матч: таймер, тикер событий, canvas-рендер поля
js/ui.js          — все экраны как HTML, делегирование событий
```

## Механики

- **Карьера**: старт от любительской лиги до РПЛ; совет увольняет при низком доверии.
- **Студия формы перед стартом**: три комплекта (домашняя, гостевая, вратарская), 24 фасона, палитра по группам и выбор цвета для каждой детали — база, отделка, шорты, гетры. Гостевая и вратарская проверяются на контраст.
- **Матч**: сегментная xG-модель (Пуассон), моментум, стили игры, давление/темп/линия, пенальти и стандарты, оценки игроков, удаления (4 жёлтые → дисквалификация).
- **Живой просмотр**: канвас-поле с формацией, мячом и тикером; длительность матча настраивается (2/3/5 минут), замены в перерыве и по ходу (до 5).
- **Сезон**: календарь по субботам с зимней паузой, призы, повышение/вылет, стыковые матчи, кубок (группы + путь регионов), еврокубки (лиговая стадия и плей-офф).
- **Состав и рынок**: адаптация позиций, старение и рост игроков, контракты, потолок зарплат, трансферные окна, входящие оферы, 25 зарубежных рынков.
- **Кабинет**: заслуги (полка трофеев), почта, финансы, сложность (новичок/опытный/про/звезда мира).

## Публикация на GitHub Pages

1. Запушьте содержимое этой папки в репозиторий (ветка `main`, файлы в корне).
2. Workflow `.github/workflows/pages.yml` опубликует сайт автоматически (Settings → Pages → Source: GitHub Actions).
3. Либо вручную: Settings → Pages → Deploy from a branch → `main` / `(root)`.
